# 🦶 Alma dos Pés — Podologia Clínica

## 📌 Sobre o Projeto

O **Alma dos Pés** é uma Landing Page desenvolvida para uma clínica de **Podologia Clínica e Preventiva**, com uma proposta visual moderna, acolhedora e profissional. O projeto foi pensado para apresentar os serviços da clínica de forma clara, transmitir confiança aos visitantes e facilitar o contato e o agendamento de avaliações.

A página destaca a importância dos cuidados com os pés, oferecendo uma experiência simples e intuitiva para que o visitante conheça os tratamentos disponíveis e encontre rapidamente as informações necessárias para entrar em contato com a clínica.

## 🎯 Objetivo

O principal objetivo do projeto é criar uma presença digital profissional para uma clínica de podologia, apresentando seus tratamentos e serviços de maneira organizada e proporcionando ao usuário uma navegação agradável e objetiva.

## 💻 Tecnologias

- CSS3 🟦
- JavaScript 🟨
- Git 📍
- GitHub Pages 📍

## ✨ Funcionalidades

- 📱 Navegação responsiva
- 🔗 Menu com navegação por seções
- 📲 Botão para agendamento pelo WhatsApp
- 🩺 Apresentação dos tratamentos
- 💬 Seção de depoimentos
- 📍 Localização da clínica através do Google Maps
- 📞 Informações de contato
- 📅 Chamada para agendamento de avaliação

## 🎨 Design

O projeto utiliza uma identidade visual voltada para **saúde, cuidado, conforto e profissionalismo**, utilizando imagens relacionadas à podologia e uma estrutura visual organizada.

A página foi construída para transmitir uma sensação de acolhimento desde a primeira seção, utilizando chamadas como **“Seus pés carregam toda a sua história”** e destacando a proposta de oferecer cuidado especializado para proporcionar mais conforto e segurança aos pacientes.

## 📱 Responsividade

A interface foi desenvolvida pensando em diferentes tamanhos de tela, permitindo que o conteúdo seja acessado de maneira confortável em **computadores, tablets e dispositivos móveis**.
